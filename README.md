# IncluWork

Plataforma móvil de empleo inclusivo para personas con discapacidad y empresas comprometidas con la inclusión laboral.

## MVP

- Registro y autenticación por roles: candidato, empresa y administrador
- Verificación de acreditación de discapacidad por país
- Perfil profesional y CV
- Ofertas laborales inclusivas
- Matching IA 0–100% con explicación
- Postulaciones y seguimiento de estados
- Chat y entrevistas accesibles
- Notificaciones
- Configuración de accesibilidad
- Panel de administración
- Reportes y métricas de inclusión

## Stack

- Mobile: React Native
- Backend: Node.js + Express
- Base de datos: MongoDB
- IA: servicios de análisis de CV, matching y recomendaciones
